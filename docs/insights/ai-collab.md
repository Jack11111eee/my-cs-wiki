# 与 AI 协作

1. 与AI或者智能体交流的时候，已经要澄清一些关键性的东西，比如：“有不确定的地方先跟我确认后再动手”、“有不确定的细节不要埋头干，先跟我对齐后再做”，这点的初衷是只要你不提，AI有自动帮你补充方案的倾向，但它做的决定有时候不是你想要的，甚至是反向的。
2. 让智能体跑任务的时候最好要定制好你的ReAct，比如要不要planning，要不要research，要不要verify等等。对于简单任务轻量化的verify可能就够了，对于复杂重型的任务则需要复杂的ReAct闭环。
3. 我一般的习惯是先跟能力强的模型聊完idea，多轮讨论收敛到一份总设计文档中，再写一份步骤文档，包括每个里程碑的gate，总之是让execute智能体能够读懂并且细分来执行。plan都做完以后，每个里程碑都独立一个session让能力中等但是便宜的智能体来执行，prompt给它约束好(包括CLAUDE.md, AGENTS.md, 我个人习惯是沿用github上的andrej-karpathy-skills，然后再让牛逼智能体帮忙根据仓库目标和实际来做细化和垂直的约束)。做完一个里程碑以后就让能力强的智能体来做一遍verify，确认里程碑已经完全闭合、gate被完成了，再进入下一个里程碑。以此循环往复，就可以完成整个项目的构建，且大部分质量还挺高，小的问题可能还是有，需要接着细化和debugging。截至2026年9月25日，我用的搭配是 claude-opus-5.5 + deepseek-v4.1-flash，个人深度体验下来（加起来至少烧了20亿token了）无论是性价比还是效率还是质量这一块，都是很过关的。
