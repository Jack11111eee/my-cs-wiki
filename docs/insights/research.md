# 科研

1. 科研下载的数据集非常大，首先确认运行服务器和数据服务器是否可以互联，其次确认存储空间是否足够，最后再做目录的确认和数据下载
2. 数据下载首先是代理。下面这个站虽然节点可能不是全绿，但是至少会有可用节点+便宜量大管饱：https://pqjc.site/register?code=fEnIhwFv&cover=sfw
3. 下载的时候要注意先测不同节点对于对方数据服务器的下载速度。再在服务器上建立节点+使用tmux，不要用反向代理转本地端口，这样一来会增加你的I/O压力，在自己使用其他网络活动的时候双方都会受到带宽影响；二来必须保证你的电脑常亮且开启，如果是台式那还好说，笔记本就会比较难受。
4. 下载机制注意：可以使用一些下载技巧来增加下载速度。多路并发+自适应分块策略+httpx支持的头复用，这是目前我用的最多的加速方法。以及退避重试机制；节点有时会不可避免的timeout或者error，那么此时就要依靠退避重试来保持连通性，防止一觉睡醒起来发现睡觉后三十分钟下载就断了，预防高血压，保持血管松弛。以及分块策略的重试机制也需要备上，丢包是很常见的事情，必须要用兜底机制。
5. 到一个新领域怎么做科研？做概要综述、详细综述 -> 看看前沿在做些什么 -> 你感兴趣或者你想钻研的某一个小领域 -> 问题是什么、大家的方案是什么、你的方案是什么 -> 做baseline实验 -> 做你的方法验证、微调 -> 直到你的方法有改进或者优化结果
6. 数据驱动的项目，先处理数据（搜集、爬、清洗、划分），再做规划，规划也需要花大功夫，不要直接稀里糊涂规划以后就上手构建实施了。
